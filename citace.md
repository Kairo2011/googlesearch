
# KairoGoogle – použité zdroje

## Google
Externí vyhledávací služba použitá pro vyhledávání textu a obrázků.

https://www.google.com/

## MDN Web Docs – HTML
Dokumentace HTML a formulářových prvků.

https://developer.mozilla.org/en-US/docs/Web/HTML

## MDN Web Docs – CSS
Dokumentace CSS pro stylování webových stránek.

https://developer.mozilla.org/en-US/docs/Web/CSS

## MDN Web Docs – JavaScript
Dokumentace JavaScriptu.

https://developer.mozilla.org/en-US/docs/Web/JavaScript

## W3C HTML Validator
Nástroj pro kontrolu správnosti HTML.

https://validator.w3.org/nu/

## W3C CSS Validator
Nástroj pro kontrolu správnosti CSS.

https://jigsaw.w3.org/css-validator/
