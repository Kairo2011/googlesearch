2. Vytvoř profesionální CSS design pro vlastní vyhledávač KairoGoogle.
3. Vytvoř barevné logo KairoGoogle v barvách Googlu.
4. Vytvoř stránku pro vyhledávání obrázků pomocí Google.
5. Vytvoř stránku pokročilého vyhledávání podle zadání CS50.
6. Vytvoř HTML stránku obsahující různé formulářové prvky.
7. Vytvoř profesionální osobní portfolio v HTML a CSS.
8. Vytvoř responzivní CSS design pro všechny stránky.
9. Pomoz s kontrolou struktury projektu a validací HTML a CSS.
